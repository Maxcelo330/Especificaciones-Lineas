Brix de trabajo — Coca-Cola

Solo para Coca-Cola original (único producto con Brix normalizado). Corrige el Brix objetivo según la inversión del jarabe terminado (J.T.): Brix de trabajo = Brix bebida + 0,2282 × (J.T. actual − J.T. fresco).

Este apartado aplica únicamente a Coca-Cola original. Selecciónala arriba para usarlo.
